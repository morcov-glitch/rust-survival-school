# Rust Survival School

An unofficial, fan-made first-person tutorial for the survival game Rust. Not affiliated with Facepunch Studios.

**Play:** open the GitHub Pages link for this repository.

## What's inside

- **Training Island** – a 3D first-person sandbox that teaches the real Rust loop: gather, craft (with blueprints, workbench levels and crafting times), bag up, hunt, build a base piece by piece, lock it, survive raids, supply drops, weather, cold, bleeding, and hostile players who fight you and each other.
- **Field Guide** – a searchable reference: resources, cloth, sleeping bags, base defence, raid costs, crafting requirements, mid-wipe survival and more.
- **Play with a friend** – peer-to-peer online co-op. One player hosts (their browser runs the island) and sends an invite link; the friend opens it and joins.

## Online play notes

- Uses WebRTC through the free PeerJS signalling server, so it works from static hosting like GitHub Pages. No game server needed.
- The host's tab runs the world. If the host closes it, the game ends for everyone.
- Works on most home networks. Very strict networks (some schools/offices, symmetric NAT) can block peer-to-peer connections.

## Controls

WASD move · Shift sprint · Space jump · Mouse look · Wheel/1–6 hotbar · Left click use · R / right click secondary & reload · E interact · Tab inventory & crafting · M map · G field guide · Enter chat (online)

Numbers follow the real game where known; Facepunch rebalances often, so treat them as approximate.
